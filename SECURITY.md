# Security

Report a vulnerability privately to **zp130221@163.com** (subject "pdfedit security").
You will get an acknowledgement within 3 days and a fix or a plan within 14 days for
anything that affects the hosted API or the published packages. Please do not open a
public issue for security reports.

What the hosted service does with your files is in the privacy policy:
https://api.niubai.vip/legal#privacy (documents deleted within 24 hours, never used
for training, never read by people except to resolve a support case you open).
